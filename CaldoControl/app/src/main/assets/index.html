Como integrar

O assistente aceita WSS JSON ou uma API HTTPS JSON/GET, sem autenticação no aplicativo. O gateway deve disponibilizar uma interface de consulta separada, autorizada pela equipe de automação e TI. OPC UA, Modbus TCP e MQTT exigem um serviço de adaptação de leitura. Se enviar limeFlow, informe a unidade.

Limites do processo

Dados e segurança

Os registros ficam armazenados localmente neste navegador. Eles não são enviados a um servidor. Para não perder os dados, faça backups periódicos.

A restauração adiciona registros sem duplicar identificadores. Se houver limites e horário operacional no backup, você poderá optar por restaurá-los. Faça cópia antes de apagar dados.

⚠️ Ferramenta de acompanhamento, não de automação industrial. Qualquer alteração de cal, polímero, temperatura ou setpoint deve seguir o procedimento operacional validado.

Sobre os indicadores

L/m³ é a vazão de leite de cal em litros por hora dividida pela vazão do caldo em metros cúbicos por hora. Baumé é registrado como leitura de densidade, sem conversão automática para teor de hidróxido de cálcio.
