Como integrar

O assistente aceita WSS JSON ou uma API HTTPS JSON/GET, sem autenticação no aplicativo. O gateway deve disponibilizar uma interface de consulta separada, autorizada pela equipe de automação e TI. OPC UA, Modbus TCP e MQTT exigem um serviço de adaptação de leitura. O aplicativo utiliza apenas tags de pH e Brix.

Formato aceito

{
  "timestamp": "2026-11-01T12:00:00Z",
  "source": "gateway",
  "tags": {
    "phCalado": 7.1,
    "phDec": 6.9,
    "phXarope": 6.0,
    "phTorre": 7.4,
    "brixCalado": 15.0,
    "brixClarificado": 15.2,
    "brixXarope": 61.0
  }

Rascunhos automáticos após o fim do turno, enquanto o aplicativo estiver aberto. Apenas o operador pode conferir e confirmar o fechamento.

Configure o início do dia operacional em Ajustes, especialmente se o turno C atravessar a meia-noite. Novas análises após a conferência deixam o fechamento desatualizado.

Faixas de referência

Limites do processo

Dados e segurança

Os registros ficam armazenados localmente neste navegador. Eles não são enviados a um servidor. Para não perder os dados, faça backups periódicos.

A restauração adiciona registros sem duplicar identificadores. Se houver limites e horário operacional no backup, você poderá optar por restaurá-los. Faça cópia antes de apagar dados.

⚠️ Ferramenta de acompanhamento, não de automação industrial. Decisões sobre o processo devem seguir os procedimentos aprovados da usina.

Sobre as medições

Os parâmetros disponíveis são pH e Brix. O backup JSON preserva registros de versões anteriores, inclusive medições antigas de categorias removidas.
