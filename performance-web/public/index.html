02 / MOD
/portperf keyExibe a chave privada para ligar mod e site
/portperf stream onAutoriza a transmissão HTTPS dos indicadores
/portperf stream offPara a transmissão imediatamente
/portperf hud onAtiva o HUD de desempenho no jogo

Os dados são armazenados temporariamente na memória do servidor do site. Uma reinicialização da hospedagem apaga o histórico. Não há coleta de TPS real, CPU ou GPU nesta versão. O ping exibido é o reportado pelo cliente Minecraft e pode ficar indisponível em singleplayer.
